🏠 A fully local smart home automation system built on Home Assistant (HAOS) and Raspberry Pi — no cloud dependencies.

Includes an ESP32-CAM fridge monitor: it streams video, has a toggleable flashlight and a door sensor, and an AI vision automation turns each snapshot into a live food inventory To-Do list — quantity, condition, confidence and a detection box, all kept in sync with a matching Lovelace card.

- ❄️ [Fridge Core](https://github.com/jan-tdy/fridge-core) — the ESPHome camera + AI inventory automation
- ❄️ [Fridge Card](https://github.com/jan-tdy/fridge-card) — the Lovelace inventory card
- 🧹 [VacuumCard ADV](https://github.com/jan-tdy/VacuumCard-ADV) — advanced vacuum control card
