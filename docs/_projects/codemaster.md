💻 A desktop app store for my own GitHub apps.

Code Master scans every jan-tdy repository and, for each one that ships a `codemaster-metadata.json` file, lists the apps it publishes — a single repo can publish several apps at once.

- **Store** — browse every published app, grouped by category, with one-click install.
- **Installed** — launch, update or remove apps, and add them to your application menu.
- **Updates** — installed apps with a newer published version, updated individually or all at once.
- **Private repos** — add a GitHub token to scan and install your own private apps too.

**Repository:** [jan-tdy/codemaster](https://github.com/jan-tdy/codemaster)
