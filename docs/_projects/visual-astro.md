🔭 A modern, web-based replacement for the classic `Reducciones.ods` spreadsheet used by visual variable-star observers.

- **Sessions** — log observing sessions and individual magnitude estimates.
- **Catalog** — manage your personal catalog of variable stars and comparison sequences.
- **Pozor** (night planning) — altitude charts, minima predictions, a CCD target catalog, an observation journal.
- **Exports** — VSNET/AAVSO-ready exports, PDF paper templates, JSON/XLSX dumps.
- **Paper OCR** — scan and import handwritten observation sheets.
- Built with Vite + React + TypeScript, shadcn/ui, and Supabase.
