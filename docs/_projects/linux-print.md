🖨️ A PyQt6 app for Ubuntu/Kubuntu (and any modern CUPS-based distro) that goes well beyond plain printing.

- **Plotter tab** — Silhouette Cameo cutting plotters (USB, Cameo 4/5): SVG/PNG/PDF import, a manual drawing tool (freehand, shape catalog, text), roll-fed vinyl support, project save/load, and print-and-cut.
- **Booklet tab** — turns a PDF into an A5 booklet printed 2-up on A4, in the page order a saddle-stitched (center-fold, stapled) booklet needs.
- **Printers tab** — USB, network and remote-CUPS-server printers with autodiscovery; a background watcher keeps re-discovering printers and fixes their device URI when it drifts, so a printer doesn't silently break when its IP or port changes.

**Repository:** [jan-tdy/linux-print](https://github.com/jan-tdy/linux-print)
